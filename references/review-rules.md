# 审查规则与阈值

所有规则只输出两类内容：**实测数据**（依据）和**对应做法**（建议）。
没有数据支撑的判断不写——「建议优化结构」这种话没有任何信息量。

## 评分

基础分 100，逐条扣：`严重 −12`、`警告 −6`、`提示 −2`、`建议 −1`，下限 0。

| 分数 | 等级 | 含义 |
|---|---|---|
| ≥85 | 优 | 规整，剩下都是可选优化 |
| 70–84 | 良 | 能做出来，有影响改型/加工的点 |
| 50–69 | 中 | 有明显问题，建议处理后再往下走 |
| <50 | 需整改 | 存在阻碍性问题 |

## 建模质量

| ID | 级别 | 判据 | 触发条件 |
|---|---|---|---|
| M01 | 严重 | 特征报错数 > 0 | `GetErrorCode2 != 0`，只统计建模特征与草图 |
| M02 | 警告 | `NeedsRebuild = True` | 有改动未重建，质量属性可能是旧数据 |
| M03 | 警告 | 欠定义草图数 > 0 | 草图 `GetConstrainedStatus != 1` 且图元数 > 0 |
| M04 | 提示 | 空草图数 > 0 | 草图图元数 = 0 |
| M05 | 警告 | 材料名为空 | 密度按默认值算，质量/质心不可信 |
| M06 | 提示 | 缺 图号/名称/材料/版本 | 工程图标题栏与 BOM 依赖这些字段 |
| M07 | 建议 | 压缩特征数 > 0 | 只统计建模特征，光源/文件夹不算 |
| M08 | 提示 | 实体数 > 1 | 多实体易在出图与 BOM 时漏项 |
| M09 | 建议 | 建模特征 ≥ 40 且无阵列/镜像 | 重复结构应该用阵列，否则重建慢、改型难 |

**为什么要盯欠定义草图**：欠定义的草图在改尺寸、切配置、装配定位时会漂移。
这是改型失败最常见的原因，比「特征多」严重得多。

## 结构合理性

### S01 / S02 细长比

```
细长比 = 最大尺寸 / 次大尺寸
```

**注意**：这里**不用** `max/min`。用 `max/min` 会把 120×120×15 的法兰盘算成
「长宽比 8.0 的细长件」——那是厚度比，不是细长，结论会误导人。

| 阈值 | 级别 | 说明 |
|---|---|---|
| ≥ 8 | 警告 | 切削/装配力下易弯曲 |
| ≥ 4 | 提示 | 留意悬伸端挠度与振动 |

### S03 质心偏移

```
偏移量 = |质心 − 包围盒几何中心|
偏移比 = 偏移量 / (包围盒对角线/2)
```

偏移比 ≥ 0.18 时警告。偏载会放大振动、增加轴承附加力矩。

### S04 等效壁厚

```
等效壁厚 ≈ 2V / A     （V=体积，A=表面积，薄壁板的经典近似）
```

低于材料下限时警告：

| 材料大类 | 下限 |
|---|---|
| 钢 | 1.5 mm |
| 铝 | 1.2 mm |
| 塑料 | 1.0 mm |

### S05 / S06 填充率

```
填充率 = 实体体积 / 包围盒体积
```

- < 0.12 → 提示：薄壁/框架结构，确认刚度是否够
- \> 0.85 且是通用件/法兰/块类 → 建议：减重空间明显

### S07 切除处无圆角

**判据**：存在切除/孔特征，且圆角与倒角特征数 = 0。

内尖角的应力集中系数可达 2–3，是疲劳裂纹的起点。
建议内角 R ≥ 0.5×壁厚，非配合锐边加 0.5–1 mm 倒角。

### S08 薄板易翘曲

板件类，且 `最大尺寸 / 板厚 > 50` 时提示。

## 可制造性

| ID | 级别 | 判据 |
|---|---|---|
| F01 | 提示 | 驱动尺寸中非整数（偏差 > 0.05）数量 ≥ 3 |
| F02 | 警告 | 建模特征 > 3 但读到 0 个尺寸 |
| F03 | 警告 | 壳体类且等效壁厚 < 2.0 mm |
| F04 | 警告 | 最薄尺寸 < 3 mm 且厚度比 < 0.05 |

**F02 值得单独说**：一个模型如果所有几何都是「画上去」的、没有任何尺寸，
那它没法参数化改型，也导不出规范工程图。这种模型后期改一处要重画一片。

---

## 可装配性

| ID | 级别 | 判据 |
|---|---|---|
| A01 | 提示 | 驱动尺寸中小于 3 mm 的 ≥ 2 个（小孔难加工） |
| A02 | 严重 | 装配体零件 > 1 且配合数 = 0 |
| A03 | 提示 | 配合数 > 零件数 × 4 |
| A04 | 警告 | 装配体零件 > 1 且没有固定件 |

没有固定基准件的装配体，整体位姿不确定，出图和仿真都会漂。

## 规范性

| ID | 级别 | 判据 |
|---|---|---|
| N01 | 警告 | 文档没有磁盘路径（新建后从未保存） |
| N01b | 提示 | 有未保存改动 |
| N02 | 提示 | 自定义属性「图号」为空 |
| N03 | 建议 | 文件名形如 `零件1` / `Part1` |
| N04 | 建议 | 配置数 > 6 |

## 零件类型判定

用于给针对性建议，按顺序匹配，先中先返回：

1. 有钣金特征 → 钣金件
2. 有抽壳 → 壳体/罩类
3. 厚度比 < 0.10 且有孔 → 板件（带孔）
4. 孔类特征 ≥ 2 且厚度比 < 0.35 → 法兰/安装盘
5. 细长比 ≥ 3 且厚度比 > 0.4 → 轴类/长条形
6. 细长比 ≤ 1.25 且厚度比 ≥ 0.35 → 块类/回转体
7. 其余 → 通用结构件

## 扩充规则的方法

在 `review.py` 里加一个 `rule_xxx(data, mt, ptype)` 函数，返回 `_mk(...)` 列表，
然后把函数名加进 `review()` 里的元组。注意：

- `id` 用「类别首字母 + 两位编号」，别和已有冲突
- `evidence` 必须带具体数值，不能只写「偏小」
- `fix` 只在能生成**可执行且可验证**的指令时才写，否则留 `None`
